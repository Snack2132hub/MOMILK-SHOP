# Frontend — MOMILK-SHOP

Vite + React + TypeScript storefront and admin UI. Existing components and styles were moved without redesigning them.

## Commands
- `npm install`
- `npm run dev`
- `npm run build`
- `npm run typecheck`

Use only `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` in browser code. Never expose service-role/secret keys.
